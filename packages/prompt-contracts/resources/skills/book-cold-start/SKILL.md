# 开书冷启动（book-cold-start）

从用户**一句话卖点**到「可写卷大纲」的硬门禁。未完成前禁止卷大纲、章规划、正文草稿与批量推演。

详细命名/对话清单见同 skill 的 `references/style-pack-spec.md`。更深手册可按需 `load_skill`：`style-bible`、`naming-consistency`、`dialogue-subtext`、`genre-style-presets`（vendor 许可见 `resources/vendor/README.md`）。

## 门禁（首轮强制）

用户开书第一句（或风格仍不合格）时，**本轮只做分析 + 风格备选**，不得写卷大纲/章大纲/正文：

1. 用一两句点破卖点题材与读者期待；
2. `list`/`request_read` `表现输出/笔风规则/`（必要时读 2–3 份候选正文），从**已有文件名**里选主锚；
3. 立刻用 `choices`（`continue_discuss`）给出 **2–3 套风格包**，每套对应**一个**可下拉的笔风文件；
4. 先 `todo_write`：风格备选 → 风格落盘 → 卷大纲 →（按需）章大纲。

禁止：只在正文写 A/B/C 让用户打字；跳过 choices 直接落盘（用户明确「按你的来」除外）；风格未合格时交 `arcPlan` / `volumeChapterPlans` / `chapterDraftProposal(s)`。

## 阶段顺序（不可跳）

| 阶段 | 做什么 | 合格标志 |
|------|--------|----------|
| S0 | 用户一句话 premise | 有可理解卖点 |
| S1 | 分析 + **2–3 套风格包** `choices` | 每套绑定笔风文件 + 含命名/对话硬字段 |
| S2 | 用户点选，或「按你推荐」 | 选定一套 |
| S3 | `presentationWrites` → `表现输出/本作品描写/作品风格.md`；并请用户把创作台**笔风下拉**切到该主锚 | 8 节均有正向定义且过实质门槛 |
| S4 | 卷大纲 `大纲/{卷}.md` | 卷主线 + ≥2 章节点 |
| S5 | 章梗概/细纲 | 当前章有细纲 |
| S6 | 正文草稿 | 仅 S3–S5 合格后 |

## 风格包 = 可选笔风（硬）

每套备选**必须**绑定工作区已有路径（勿 invent 文件名）：

`表现输出/笔风规则/{已有文件名}.md`

常见题材→笔风对照（优先从此表挑；表外题材仍须落到真实文件名）：

| 题材倾向 | 优先笔风文件 |
|----------|----------------|
| 东方玄幻/升级流 | `东方玄幻.md` / `网文白话.md` |
| 仙侠 | `仙侠.md` |
| 都市/日常 | `都市.md` / `网文白话.md` |
| 都市异能 | `都市异能.md` |
| 高武 | `高武.md` |
| 言情/甜宠 | `言情.md` |
| 悬疑/推理 | `悬疑恐怖.md` / `侦探推理.md` |
| 规则怪谈 | `规则怪谈.md` |
| 克苏鲁 | `克苏鲁.md` |
| 历史/争霸 | `历史争霸.md` / `架空历史.md` |

**笔风预设只读**：不得 `presentationWrites` 改写 `笔风规则/`。落盘后在 `assistantMessage` 明确：「请把创作台笔风下拉切到 `表现输出/笔风规则/××.md`」。

### 每套 `choices` 卡片（assistantMessage 展开；label 浓缩）

每套至少写清（缺一项 = 不合格备选）：

1. **笔风主锚**：完整相对路径  
2. **叙述旋钮**：人称（一/二/三限知/三全知）+ 语气基调（硬朗/热血/戏谑/克制/轻松…）+ 描写密度（精简/适中/细腻）+ 对话占比（高对话/均衡/叙述主导）  
3. **命名规则**：人/地/势力/物·号取法 + **≥2 正例 + ≥1 反例**（防撞名：常同框角色须错开姓/首字/字形/音节）  
4. **对话方式**：口语度/文白、句长偏好、群戏是否禁乒乓、主角对白示例 **1 句**  
5. **80–120 字风格样句**（用本卖点场景，不得抄通用套话）

`choices[].label` 建议形如：`【笔风·东方玄幻】第三人称限知·硬朗短句·名例林烬/沈砚`（用户一点即发送该 label）。

## 作品风格 8 维（落盘硬模板）

路径：`表现输出/本作品描写/作品风格.md`  
`##` 标题须字面一致。宿主除「待定」外，还会检 **命名 / 声口 / 人称 / 句子与对话 / 语体笔风** 是否含实质字段（见下）。

```markdown
# 作品风格

> 整部作品硬约束。人称/命名/声口/对话以本文件为准；描写/笔风下拉只管机位与腔调预设，不能改写本文件已定人称与命名。
> 开书须先给出 2–3 套风格备选（choices），用户选定或「按你的来」后再把下列 8 维写成正向定义。

## 1. 语体笔风
- 主锚：表现输出/笔风规则/××.md
- 叙述腔 / 语气基调 / 描写密度 / 感官侧重

## 2. 时代科技生活
（日常物、科技、货币、机构怎么出现）

## 3. 规则称谓能力
（世界用语与战斗/能力怎么落笔）

## 4. 命名
- 人名规则（音节结构、姓氏策略、防撞名）
- 地名 / 势力 / 物品·功法·编号
- 正例 ≥2、反例 ≥1

## 5. 角色声口
- 主角：句长、词汇标记、示例句
- 至少 1 名关键配角对照（遮住名字应能分辨）

## 6. 尺度意象章钩
（暴力/恐怖/幽默边界、意象、章末钩习惯）

## 7. 人称指称
- 人称类型；正文以「我」还是姓名为主；示例句；信息边界（限知不可写主角不知之事）

## 8. 句子与对话
- 句长与断句；对白口语度/文白；对话占比倾向
- 群戏规则（禁对白乒乓 / 反应分层）
- 潜台词与权力话轮偏好（可简写）
- 主角对白示例 + 不合格对白反例各 ≥1
```

## 禁区

- 风格未合格时交草稿 / 卷章规划 / 卷大纲，或声称「可以开始推正文」。
- 风格包不绑真实笔风文件名，或三套共用同一空洞「网文感」。
- 命名/对话只写「古风一点」「口语一点」而无规则与示例。
- 用一串「禁止」代替正向定义；小节仍写「待定」。
