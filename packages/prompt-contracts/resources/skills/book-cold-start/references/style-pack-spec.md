## B. 命名规则（写入 §4，硬）

辨识度优先于「好听」。常同框要角必须在**姓/首字、字形偏旁、音节结构**至少两项错开。

### 必写字段

1. **人名规则**：双音节/三音节/单名/复姓策略；是否允许复姓墙；年龄/阶层如何从姓名区分。  
2. **防撞名**：禁止同批要角同姓堆叠、同偏旁墙（如全员「凌×」）、首字全同。  
3. **地名 / 势力**：功能可读（正派/魔道/商会各有构词习惯），统一写法。  
4. **物品·功法·编号**：数字+名 / 意境+动作 / 属性+效果 — 选一种主构词，附 1 例。  
5. **正例 ≥2、反例 ≥1**（反例写「为什么不合格」）。

### 题材提示

| 题材 | 推荐 | 反例 |
|------|------|------|
| 玄幻 | 古风但不全员一个味：林烬、沈砚、顾停舟 | 凌寒、凌霜、凌月同批 |
| 都市 | 常见姓名 + 年龄感：张远山、李小鹿 | 全员慕容/上官 |
| 仙侠 | 俗名+道号双轨：陈三 / 清虚子 | 全员道号且雷同 |
| 西幻/异界 | 同一文化共用音节库；能念出 | 中英日名无规则混堆 |
| 历史/古言 | 时代用字与避讳意识 | 现代网名硬塞进朝堂 |

仙侠/宗门可另定：势力名（天剑宗 vs 血魔殿 vs 万宝阁）分层，勿全家「×天×地」。

## C. 对话与声口（写入 §5 / §8，硬）

### 声口矩阵（每名要角至少）

- 声音基调、句长形状、词汇来源（职业/阶层/地域）  
- 社交策略（直球/绕弯/嘲讽）、压力漏点  
- **示例句 1 条**（可进正文气质，禁止当章复读）

遮住名字应能分辨说话人；三人以上对白至少两类句长或词汇偏好。

### 对话系统必写

1. **口语度 / 文白**：白话直给 / 半文白 / 古白（须与时代层一致）。  
2. **禁对白乒乓**：禁止无动作、无反应的「问-答-问-答」审讯腔；对白间要有动作拍或现场反馈。  
3. **群戏反应分层**（可简写）：直接受损者 → 权力高位 → 利益相关 → 情绪外露 → 旁观风向。  
4. **潜台词**：真实动机不写在台词表面；用回避、称呼变化、沉默、只答一半承载。  
5. **权力话轮**（可选但推荐）：上位者短句冷静，下位者话多情绪化；压制/反转场景可用「长篇 vs 一字」。  
6. **不合格对白反例 ≥1**（如全员同一书面腔、互讲已知信息、每句「他笑着说」标签）。

### 常见禁区（写入 §8 时可择要）

- 不做元叙述（「让我们看看」）。  
- 少用「缓缓/淡淡/微微」堆笑容与动作。  
- 对白功能：推进 / 期待 / 人设，至少占一项；纯寒暄删。

## D. 风格样句

选定或推荐套落后，用本作品场景写 **80–120 字**样句，标出体现了哪些旋钮（人称、密度、对白）。样句进 `assistantMessage` 或 §1 末；**不要**当成设定事实入库。
