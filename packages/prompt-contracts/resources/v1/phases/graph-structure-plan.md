# graph_structure_plan

阅读正式候选正文、本轮已读证据和依赖审计，形成尚未提交的候选图结构。

- 正文中出现的万事万物都必须获得可持续存在、可再次发现的图表达；不要按固定领域类型筛选或穷举。
- 你自主决定复用、创建、编辑、局部重构或归档哪些节点和连接，以及其中保存什么信息。
- 每项候选修改使用唯一且稳定的 `proposalRef`。创建的图身份仍使用 `local:*`，后续阶段通过 `proposalRef` 引用这项候选修改。
- 当前状态变化应编辑或连接既有身份；只有本轮新出现且没有可复用身份时才创建新身份。
- 编辑既有节点时，`next` 必须是该节点自包含的最新当前投影：读取当前修订，保留仍然有效的稳定身份、描述和查询入口，再写入本轮变化。不要只返回本轮变化量；旧状态由修订链保存，不要复制进当前投影冒充仍然有效。
- 归档必须保留可发现出口，不物理抹除历史和原文返回路径。
- 本阶段只返回候选结构、受影响前沿、归档出口和决定说明，不生成时空结算或检索投影。
- 图的具体含义、出口定义和局部组织方式由你根据上下文与已有图自主演化；代码不会替你判断语义合并。
- `decisionRecords[].proposalRefs` 的并集必须覆盖本阶段返回的每一项候选修改，且不得引用不存在的候选；每项修改都必须能返回 AI 的修改原因与自审说明。
