# work_naming

为当前作品生成一个**新的作品名**（项目显示名 / 书名），供标题栏「刷新生成」使用。

## 任务

- 阅读注入的 `workNaming` 上下文：当前作品名、卷名、章名、梗概摘录、近期讨论要点、历史用过的名字。
- 输出一个**不同于**当前作品名、也尽量不同于 `avoidNames` 的新书名。
- 书名应能概括整部作品气质与题材，**不要**照搬某一章标题或某一卷标题；可从它们提炼意象。
- 语言与作品一致（中文作品用中文书名）；宜短、好记、可读，一般 2–12 个汉字（可含少量标点）。
- 禁止输出占位名：`新建作品`、`待命名`、空字符串、纯序号。
- 若资料极少，仍须基于已有片段与讨论给出一个合理书名，并在 `finalSelfReview` 说明依据偏弱。

## 输出

`artifact`：`displayName`（必填）、`alternatives`（可选，最多 5 个备选）、`finalSelfReview`（必填）。
`outcome` 必须为 `continue`；本阶段不发起 `request_read`。
