# graph_spacetime_settlement

在容量已经通过的稳定候选结构上结算时间、空间、历史与生效关系。

- 为依赖审计中的每个场景建立对应绑定，保持场景索引和前置场景索引一致。
- 自主确定场景的时间、地点、参照系、实际过渡路径和跨参照对应关系，不预设单一世界时钟或空间类型。
- 任何事物都可以在特定世界中承担时间或空间定位，但放入 `timeAnchorRefs` 或 `locationAnchorRefs` 前必须确认其当前图含义或可达局部确实能够恢复对应的时间顺序、时间位置或空间位置；仅仅可读、相关或出现在场景中不构成锚点用途。
- 使用稳定 `proposalRef` 声明每项候选修改在哪些场景生效，以及它是世界变化还是表示结构重构。
- 当前有效入口、前置修订和历史返回路径必须完整；历史不得因当前状态覆盖而消失。
- 新世界或新局部可以依据正文与上下文合理补全，不因没有旧资料而拒绝结算。
- 只返回时空与历史结算，不重写候选结构或检索投影。
