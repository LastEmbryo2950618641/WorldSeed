# semantic_review

使用旧图、完整提案、修改原因、证据和基础规则重新审批图治理结果。

- 不继承 graph_governance 的通过结论。
- 检查身份复用、当前状态连续、双向可发现、局部简洁和归档返回路径。
- 按效果而非固定字段审批 AI 自主演化的局部组织：它必须在有限预算内准确、选择性地恢复相关当前状态、历史过程和小说原文，理论可达但需要大范围无关展开不能批准。
- 检查正文中全部事务的演化过程与当前有效状态均有表达，旧状态不会覆盖新结果，重构也没有切断历史和原文返回路径。对可精确复述或再次指代的正文片段，检查图投影是否保存精确文字入口并连接到主体、场景、时空和演化路径；仅存在章节来源投影不算完成图表达。
- 以已读图的历史修订和当前状态作为连续性基准；图、设定集、参考文件均未覆盖的事物，只需验证其本轮推演的时空与因果入口，不得因缺少旧资料拒绝它。正文出现的万事万物都必须有图表达。
- 检查新增结构是否确实服务于正文并保持局部简洁；不以固定数量替代语义判断。声称复用的决定必须引用本轮已读图身份，章节 evidence ID 不是图身份；本轮首次出现的新事物可以由本轮新建局部结构表达。
- 检查 `affectedFrontierRefs` 是否只包含能够独立继续、暂停或归档并可被重新发现的局部演化入口。它不是修改项、节点或连接的逐项清单；一个前沿可以承载多项修改。发现把全部修改引用直接列为前沿时，应退回图治理收敛前沿集合，而不是留给结算阶段猜测或归并。
- 检查提案只使用本轮实际读取资料与同 scope 新内容。
- 批准项、退回项和验证探针都是审查建议；可以只列出实际发现的问题，不需要穷举无异议项。需补资料时建议后续检索，需改结构时建议后续图治理，但本轮正文和图仍直接提交。只要时间、地点和既有状态没有矛盾，不因新事物缺少旧资料而拒绝整轮正文。
- 代码只执行你的结构化审批，不替你判断世界语义。
- 对实际发现的问题给出明确索引或引用；未列出的部分表示本轮没有额外审查意见，不要求重复图治理阶段的完整清单。
- 返回你实际执行的 `verificationProbes` 作为审查建议，填写实际观察到的 `read-*` 与图引用。探针可以按本轮复杂度选择性提供，不要求为每个场景或修改穷举探针；缺少探针、探针不确定或探针失败都只能形成审查建议，不得阻止正文和图提交。
- `commit_review` 只给建议，不拥有拒绝提交权限。当前阶段的拒绝只表示需要回到图治理重新形成完整结果。
