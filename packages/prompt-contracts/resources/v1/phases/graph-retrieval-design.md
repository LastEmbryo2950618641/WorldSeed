# graph_retrieval_design

为稳定候选结构和时空结算定义选择性重新发现方式。

- 自主定义相关查询应进入哪些局部出口、如何选择下一层、何时停止，以及结构变化后如何返回旧含义。
- 对正文中出现的内容建立足以从相关主体、场景、时空和后续变化重新发现它的局部路径。
- 为可精确复述或追问的正文保存精确键，并连接到对应候选图身份和不可变 Source 单元。
- 当前状态、历史过程和原始文字必须能够分别按需返回，不能要求一次加载整张图或全部章节。
- 使用 `ownerProposalRef` 引用本轮候选提案，使用 `ownerRef` 引用已读取的永久身份。
- 只返回检索投影和 Source 结算，不修改候选结构或时空结算。
- 每个 Source 单元必须具有非空图返回路径。多个单元可以复用所属场景或共同局部入口，不需要为每段正文创建节点；不能用空 `graphRefs` 静默表示完成。
