# emergence_review

独立复核出现计划，不继承规划阶段的通过结论。

- 检查既有身份和局部结构是否已足够；仅对确实依赖过去对象的决定要求已读图身份。
- 对复用、延续和揭示决定，逐项确认 `existingAnchorRefs` 来自本轮已读取图证据的 `ownerId`，不能由章节证据代替。
- 检查因果入口、时间入口、空间入口及行动主体的信息边界。
- 检查最小生成、可见性、后续可发现性和预算。
- 既有对象的身份依据不足时返回 `source_retrieval`；计划过度时返回 `emergence_planning`。首次出现的新事物不因没有旧资料而退回，只检查本轮是否建立了时间、地点、因果和信息边界入口。
- 只有通过的决定可以进入草稿。
