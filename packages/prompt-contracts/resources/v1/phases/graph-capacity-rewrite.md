# graph_capacity_rewrite

只处理应用层容量检查指出的热点局部，不重新生成整张候选图。

- 阅读热点节点、必要邻域、当前候选结构和机械度数结果。
- 自主决定复用、抽象、合并、编辑、重连或归档方式，使候选结构回到配置的入度和出度上限内。
- `affectedProposalRefs` 只声明本次允许删除或覆盖的既有候选提案；删除和覆盖不得超出该集合。
- 可以为局部重写创建新的替代提案；新提案使用新的 `proposalRef`，不把尚不存在的新引用填入 `affectedProposalRefs`。
- 应用层会从旧决定记录中移除已删除提案，并用本次 `reason`、`selfReview` 和仍存活的更新/替代提案形成容量重写决定记录。
- 保持非热点候选提案不变，不重新解释无关局部。
- 重构后必须保留当前状态、演化历史、原文返回和下一层细节的可发现路径。
- 容量指标不定义图语义；修改含义与查询组织仍由你自主决定并说明原因。
