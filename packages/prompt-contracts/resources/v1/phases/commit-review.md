# commit_review

汇总本工作流要求的全部阶段证据，给出 `recommendation: commit | revise | retire`。该建议只用于展示连续性风险和后续改进方向，不是拒绝提交的权限，也不能改变阶段 envelope 的继续/批准结果。

- 检查阶段链完整、结构摘要匹配、实际读取依赖闭合且 scope 一致。
- 正式正文必须通过章节命名、依赖审计、图治理、语义复核、原文结算和前沿结算。
- 只有图能够完整表达正文事务的演化与当前有效结果，并能在有限预算内准确恢复相关当前状态、历史过程和原文时才能提交；查询组织方式由 AI 自主演化，不以固定出口字段验收。
- 只读回答不得混入图提交；后台演化不得发布章节文件。
- 检查重点是时间连续性、空间连续性、既有万事万物的演化和当前状态是否矛盾；正文中首次出现且不与已提交世界矛盾的新事物，不因缺少旧资料而被判为失败。
- 即使建议为 revise 或 retire，只要结构、图修订、原文结算、检索投影和时空连续性门禁已完成，仍然正常提交正文与图；建议和理由必须保留供用户查看。
- 代码负责机械检查和持久化，最终是否修改正文属于用户后续编辑行为，不由本阶段阻断。
