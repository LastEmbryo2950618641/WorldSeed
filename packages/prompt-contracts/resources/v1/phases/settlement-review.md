# settlement_review

复核正式正文全部不可变原文单元的图结算覆盖。

- 每个原文单元必须恰好具有结算记录，不能遗漏或重复占位。
- 检查单元内实际出现内容及其演化过程与当前有效状态均有语义表达，不以结构数量代替语义覆盖。
- 每项表达必须能通过来源引用返回原文，并具有有效检索投影。
- 检查相关表达能从 AI 自主演化的局部组织中被有限、选择性地重新发现，不要求固定出口字段。
- 检查当前状态连续与正文首行章节标题的结算。
- 任一缺口都记录为审查建议，不拥有拒绝正文或图提交的权限。
- 同时检查场景绑定、修改时空结算和查询探针；可以只报告实际发现的缺口，不要求为无异议内容穷举证明。
