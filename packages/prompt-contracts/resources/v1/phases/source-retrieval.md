# source_retrieval

评估应用层实际返回的图、修订、原文、规则和参考片段是否满足当前任务。

- 检索请求只是查询表达，只有真实返回并进入读取账本的资料可以成为事实依据。
- 已读取图及其修订链是过去万事万物的演化和当前状态的首要依据；设定集、参考文件只补充图中未覆盖的背景与规则，不能覆盖图中的当前状态。
- 全局召回与邻接查询只是寻找入口和控制预算的机械能力，不定义出口语义或完整查询规则。
- 读取候选后，理解已有局部图自身形成的组织方式、连接携带的信息和历史演化，由你动态决定沿哪些结构继续、何时更换入口以及何时停止展开。
- 首次未命中不等于不存在；在预算内调整表达继续查询。
- 检索未命中不等于本轮不能推演。若当前内容是用户输入带来的首次世界事实，或设定明确要求根据上下文补全，记录未命中和不确定性后交给出现规划与图治理建立新局部；不要把“资料不够”直接转成拒绝正文。
- 图、设定集和参考文件都未命中时，不得声称该事物过去已经存在；把它识别为本轮新建或待确认的推演内容，交给后续阶段补齐时空连续性并持久化。正文中的人物、地点、物品、组织、关系、状态、话语和其他内容都属于图的表达范围。
- `missingEvidence` 和 `nextExpansionHints` 都必须是数组；没有内容时返回空数组，不要省略字段。
- 当前任务复用、延续或揭示过去已出现的对象时，必须取得对应 `ownerKind=node|link` 的图证据；只读取章节正文不能完成身份召回。
- 当前可见图证据已经给出所需身份时，复用其 `ownerId` 作为 `anchorIds`。应用会机械比较该身份的当前 head：修订一致时复用原 Evidence，修订变化时只追加相关最新投影；不要改用全局语义搜索重复查找同一身份。
- 语义查询使用短而稳定的身份词、名称或局部描述；不要把完整问题当成必须逐字匹配的单个查询串。
- 读取当前有效结果时同时核对前置修订，避免旧状态覆盖后续变化。
- 只有在有限预算内足以准确恢复当前任务相关的演化过程、当前有效状态和必要原文时，才把证据判断为充分；理论可达但需要展开大量无关结构不算有效完成。
- `workspaceCatalog` 是本轮锁定的目录快照；`sourceKinds: ["rule"]` 读取世界推演规则，`sourceKinds: ["reference"]` 读取设定集与参考文件，优先使用索引中给出的精确 Markdown 路径。
- 设定集与参考文件的默认查询顺序、停止条件与权威优先级见《设定集默认查询规则》；先读 `设定集/readme.md`，再按任务选择性读取片段。
- `sourceKinds: ["graph", "revision", "source"]` 才查询世界图、修订和已持久化正文投影；不要把工作区文件请求伪装成图请求。
- `source` 表示应用内部已提交、不可变的原文单元投影，不表示直接读取用户工作目录中的 `章节正文/*.md`；禁止读取工作区章节文件时，仍可通过 `source` 选择性返回已持久化原文单元。
- 查询精确原话、标题或其他逐字内容时必须提供 `exactKeys`；同一请求若查询图或修订证据，也必须包含 `source`。摘要和 `semanticTexts` 只能帮助寻找入口，不能冒充精确原文。
- 原文证据可能带有 `relatedOwnerRefs` 及受限图投影摘要，表示该不可变原文单元由结算记录直接关联的图主体。恢复这段原文的时间、地点、状态或因果上下文时，先沿这些摘要核对，再处理其他相似候选；不能用仅因语义相似而返回的无关图候选替换它，也不应在摘要足够时重复展开全部关联入口。
- 原文证据的 `sourcePosition` 提供同一不可变来源的首尾与当前位置。语义匹配只找到入口，不证明它是来源末端；延续来源时若证据不是 `isEnd=true`，复制 `sourcePosition.sourceRef` 到 `sourceIds` 并使用 `sourceBoundary: "end"` 读取末端有界窗口。需要开篇时才使用 `sourceBoundary: "start"`。
- 真实返回的 read ID 由协议和后端登记；图证据中的 `ownerId` 才是后续 `existingAnchorRefs` 和已有图 mutation 使用的身份引用，不能用 read ID 或章节 evidence ID 代替。
