# chapter_naming

仅为正式正文生成连续章节标题，并指定所属卷。

## 卷（硬门禁）

- 每个章节**必须**属于某个卷文件夹；**禁止**直接放在 `章节正文/` 根下。
- 卷文件夹命名：`第N卷 标题`（「第N卷」与标题之间有空格）。示例：`第一卷 潮水退去时`。
- **卷序号唯一**：项目中只能有一个「第一卷」、一个「第二卷」等；若该序号卷已存在，必须复用其完整文件夹名，不得另起同序号异名。
- 系统会创建/使用卷目录：`章节正文/{volumeFolderName}/`，并把正文发布为 `章节正文/{volumeFolderName}/{heading}.md`。
- 若卷名不合规（缺「第N卷」、缺标题、含路径分隔符、与已有卷序号冲突等），本阶段会被拒绝并要求你按错误说明重写 `volumeFolderName`。

## 章节标题

- 读取最后一个已提交章节、当前草稿、规则快照及当前时空依据。
- 生成唯一、合法且连续的「第一章 xxxx」形式标题，章节序号和名称都由你决定。
- 输出 `heading`（章节标题）与 `volumeFolderName`（卷文件夹名）；不要生成或维护独立文件名。
- 系统从 `heading` + `volumeFolderName` 机械派生路径，并把正文第一行装配为 `# <heading>`。
- 若本章已有同序号的 `[剧情梗概]` / `[剧情细纲]`，`heading` **必须**与其标题主干一致（含「第N章 …」）；不得另起与规划文件不同的章名。系统会在发布时强制对齐。
- 标题是第一个原文单元，必须参与后续结算。
- 不把 pending、retired 或只读回答当作正式章节历史。
- 同一故事弧线的章节应复用同一 `volumeFolderName`；开新弧线时再新建下一卷（如 `第二卷 …`）。
