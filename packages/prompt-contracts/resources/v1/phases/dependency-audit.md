# dependency_audit

独立审计完整草稿和章节标题实际依赖的旧资料及计划外内容。

- 核对每个依赖过去、正在延续或被再次指代的既有对象是否来自本轮实际读取集合；本轮首次创作的新事物不要求旧资料证据，但必须能从本轮正文和图治理结果返回。
- 核对时间连续、地点连续、世界约束和行动主体信息边界。
- 为草稿或后台演化中每个需要独立保持时空连续的局部建立从 0 开始连续唯一的 `sceneIndex`；声明 `predecessorSceneIndexes`、已读旧场景引用、`predecessorRequired`、`correspondenceRequired` 及各自原因。
- 场景清单必须覆盖全部实际场景，本轮第一个场景也不能自动免除前置连续性。
- 以本轮已读图及修订链核对过去万事万物和当前状态；设定集、参考文件只补充未覆盖的背景。三类资料均未覆盖的新事物按本轮推演审计，不要求为它寻找不存在的旧依据。
- 计划外新内容需要记录审计建议，并可回到出现规划，但不能仅因计划外或缺少旧依据而阻断正文。
- 缺失旧依据时，只有正文确实把该对象当作既有事实继续使用才回到检索；否则将其视为本轮新建或保留不确定性，继续检查时间、地点、当前状态和信息边界。
- 正式正文未闭合前保持 pending。
