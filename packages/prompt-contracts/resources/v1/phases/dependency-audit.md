# dependency_audit

独立审计完整草稿和章节标题实际依赖的旧资料及计划外内容。

- 核对每个依赖过去、正在延续或被再次指代的既有对象是否来自本轮实际读取集合；本轮首次创作的新事物不要求旧资料证据，但必须能从本轮正文和图治理结果返回。
- 正文具体陈述过去动作、持续状态或既有结果时，支持它的 Evidence 必须直接覆盖同一主体、动作或状态以及结果；仅仅提到附近地点、相关对象或相似主题不构成充分依据。现有 Evidence 不足时请求选择性读取，仍无命中则保留不确定性，但不拒绝整轮正文。
- 核对时间连续、地点连续、世界约束和行动主体信息边界。
- 为草稿或后台演化中每个需要独立保持时空连续的局部建立从 0 开始连续唯一的 `sceneIndex`；声明 `predecessorSceneIndexes`、已读旧场景引用、`predecessorRequired`、`correspondenceRequired` 及各自原因。
- 场景清单必须覆盖全部实际场景，本轮第一个场景也不能自动免除前置连续性。
- 请求尾部会明确给出本阶段所属工作流和已持久化正文单元数量，必须以该值为准，不能根据正文措辞或旧阶段产物把普通推演误判成后台演化。
- 已存在正文单元时，`sceneContinuity` 不得为空，必须根据完整草稿建立覆盖全部实际场景的清单，供后续图治理把每个正文单元绑定到对应场景；只有没有正文单元的后台演化才可能没有正文场景。
- 由 AI 自主提炼正文中“其真实性依赖某种时间关系成立”的表达，写入 `temporalClaims`；不使用固定时间词表、正则分类器或预设时间关系类型，也不能因为表达方式陌生而跳过。正文中确实没有此类表达时返回空数组。
- 每个时间断言使用唯一稳定的 `claimRef`，定位 `sceneIndex`、正文单元和原文片段，自由说明参照事件或状态、时间流或参照系、关系含义、当前结论、依据及仍缺少的资料。代码只检查引用和覆盖，不替你解释自然语言。
- 时间断言所需证据已经在当前可见链或 `readEvidence` 中时直接使用；只有相关历史已被移出可见上下文且现有 Evidence 无法返回时才请求选择性读取。仍无命中时保留不确定性，不阻断正文。
- 以本轮已读图及修订链核对过去万事万物和当前状态；设定集、参考文件只补充未覆盖的背景。三类资料均未覆盖的新事物按本轮推演审计，不要求为它寻找不存在的旧依据。
- 计划外新内容需要记录审计建议，并可回到出现规划，但不能仅因计划外或缺少旧依据而阻断正文。
- 缺失旧依据时，只有正文确实把该对象当作既有事实继续使用才回到检索；否则将其视为本轮新建或保留不确定性，继续检查时间、地点、当前状态和信息边界。
- 正式正文未闭合前保持 pending。
