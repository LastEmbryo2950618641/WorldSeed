# 设定集修订规则

在 **创作台剧情梗概讨论** 及用户明确要求维护世界材料时，你可能需要 **新增或修订设定集**（`设定集/` 下的 Markdown）。本规则说明如何撰写、组织与提交设定修订；查询既有设定时仍遵循《设定集默认查询规则》。

## 1. 何时修订设定集

### 正式推演（`settings_extraction` 阶段）

正式推演在 **正文生成后、图治理前** 会进入 **设定抽取** 阶段。该阶段从本章草稿中识别应沉淀到设定集的材料，并以 **提案** 形式输出；**用户确认采纳后** 才写入 `设定集/`。此后才继续图治理与自洽演化。

- 正式推演中 **不得** 在设定抽取阶段之外静默写入设定集；
- 若本轮无新设定，抽取阶段返回空提案，推演直接进入图治理。

### 创作台梗概讨论

在梗概讨论中，先把可沉淀信息写入工作区 **`暂存区/`**（中间态）。需要写入权威设定时：

1. 产出 `stagingPromote`（完整 Markdown + 目标路径）；
2. 在 `choices` 中给出 `promote_staging`；
3. **等待用户确认落盘**；确认前不得声称已写入 `设定集/`。

在梗概讨论中，若出现以下情况，应**提议**修订设定集（而非只在对话里口头约定）：

- 本章梗概依赖**尚未建档**的人物、地点、势力、规则、术语或关系；
- 需要将讨论中已确认的世界细节**沉淀**为可检索的设定，供正式推演读取；
- 用户规则或梗概要求引用固定设定，但索引中无对应文件或内容不足；
- 用户明确要求补充、修改或拆分设定文件。

以下情况 **不要** 直接改设定集：

- 仅讨论情绪、节奏、选项而未形成可落盘的世界事实；
- 与已提交正文、已读取图当前状态冲突且用户未确认处理方式；
- 属于本轮推演才会首次出现、且更适合在正式推演 **设定抽取** 阶段沉淀的内容（梗概中可标注「待推演建立」）。

## 2. 用户确认（硬门禁）

**任何**设定集写入或覆盖前必须：

1. 用一句话说明意图、受益章节/范围；
2. 列出与已提交正文、图、用户规则、已有设定的可能冲突；
3. 给出建议：「仍要更新 / 绕开写梗概 / 放弃」；
4. **等待用户明确同意**（创作台通过「确认落盘」/`promote_staging`）；不得替用户保存，不得在 JSON 回复中假装已写入。

用户同意后，由应用写入 `设定集/`（并更新 readme 索引）；你的职责是给出**完整、可直接落盘的 Markdown 草稿**与目标路径（放在 `stagingPromote.settingsWrites`）。

## 3. 文件组织

- 根目录固定入口：`设定集/readme.md`（不可删除）；**每次新增/重命名/拆分文件后，必须同步更新 readme 索引**；
- 一主题一文件优先：如 `设定集/人物/林照.md`、`设定集/地点/盐雾城.md`、`设定集/势力/北境商会.md`；
- 路径使用中文或语义清晰的文件夹分层；文件名应稳定、可检索，避免「新建.md」「临时.md」；
- 单文件过长时按 **身份 / 地点 / 势力 / 规则 / 术语** 拆分，并在 readme 中交叉引用。

## 4. 推荐文档结构

每个设定文件建议包含（可按题材增减）：

```markdown
# {标题}

> 适用范围：{全书 / 第 N 章起 / 某线}; 关键词：{…}

## 身份摘要
（一句话说明是什么）

## 当前约束
（对本作品推演仍有效的规则、状态、禁止项；区分「已发生」与「规划」）

## 细节
（外观、历史、关系、能力、地点特征等）

## 叙事边界
（不可提前揭示、仅特定主体可知、与大纲相关的揭示节奏）

## 关联
（相关设定路径、图入口提示、用户规则引用）
```

写作要求：

- **已发生事实**与**未来规划**分开写；规划不得伪装成过去已提交事实；
- 使用稳定称谓，与正文、梗概、图节点命名保持一致；
- 不写完整章节正文；设定是材料，不是表现输出；
- 新增术语在 readme 索引中补一行：路径、关键词、适用条件。

## 5. 修订已有文件

- 先按《设定集默认查询规则》读取现有全文，再提议修改；
- **增量修订**优先：在对应章节下追加或改写，避免无说明的大段删除；
- 若用户手工编辑过设定（与 Agent 上次写入不一致），**必须**视为用户意图，不得悄悄改回，除非用户明确要求；
- 需要推翻旧设定时，在文档中用「修订说明」记录原因，并提示与已提交正文/图的一致性处理。

## 6. 与梗概、推演目标的关系

- 梗概文件（`章节正文/…[剧情梗概].md`）写「本章发生什么」；设定集写「世界是什么、约束是什么」；
- 梗概中可引用设定路径（如「见 `设定集/人物/林照.md`」），但不应把大段设定全文粘贴进梗概；
- 推演目标（goal）描述叙事目的；设定集描述世界材料。二者可互相引用，不要混为同一文件。

## 7. 硬边界

- 不得修改 `世界推演规则/基础规则/` 下任何平台只读文件；
- 不得用设定集修订绕过图治理、提交复核或用户确认；
- 不得将参考文件内容原样复制为设定集而不加采用说明；
- 用户规则在明确适用范围内优先；与本规则冲突时，以基础规则与用户明确选择为准。
