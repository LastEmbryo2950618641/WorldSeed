# 中文网文正文质量与逻辑（全作品通用）

写正文草稿、正式推演正文、修订正文时必须遵守。梗概/细纲可简写，但不得用梗概腔冒充正文。

> **去 AI 味 / 对话 / 人味 / 情绪演出 / 句式节奏**：以平台 Skill（阶段默认包或 `load_skill`）加载的 vendor 原文为准（`resources/vendor/chinese-webnovel-skills/`，[tance-mang/chinese-webnovel-skills](https://github.com/tance-mang/chinese-webnovel-skills) MIT）。系统规则只常驻短索引，不塞全文。本文件**不替代**那些 skill。  
> **本文件专责**：WorldSeed 交付硬闸、冲突密度、章钩/连贯、平台特有约束（共体、标签、计数等）。  
> 另参考（未全文 vendor）：[zenstory-ai/oh-story-claudecode](https://github.com/zenstory-ai/oh-story-claudecode)、[op7418/Humanizer-zh](https://github.com/op7418/Humanizer-zh)、[LifelongLazyLearner/qu-ai-wei](https://github.com/LifelongLazyLearner/qu-ai-wei)、[LAY-lgtm/novel-writing-framework](https://github.com/LAY-lgtm/novel-writing-framework)。无许可证仓库不纳入。

## 0. 交付硬闸（写完先自查，不过则改后再交）

正文 `chapterDraftProposal(s)` 交付前，下列任一命中必须删改，禁止「写完再润色」 internally 跳过：

1. **复盘已演场面**：禁止「你刚才说了三句话 / 一句问一句摆条文 / 他明白了这意味着」式作者复盘。
2. **正反解释腔**（叙述层，含变体）：禁止「不是A而是B / 是A不是B / 不A，是B / 觉不出A，只觉出B / 手不是他的」等作者替读者归纳；改成单一动作、生理反应或一句结论。台词里偶发可留，但勿连发机锋对诗。
3. **否定排比**：禁止「没有…没有…」「不是…也不是…只是…」连发。
4. **音量反差模板**：禁止「声音不大，却…」。
5. **代写心理怕什么**：禁止「他不是不敢，他是怕…」；用捏纸、停顿、抢话演。
6. **双收束升华**：章末禁止对仗双「他知道… / 也知道…」；只留一个动作或一条具体信息。
7. **破折号癖**：叙述层少用 ——；能用句逗就别用。
8. **空话升华**：禁止命运齿轮、空气凝固、时间静止、未来可期、意义深远。
9. **推理一次讲透**：禁止角色长段把全部推导口播完；先落可观察证据，再给最短结论，中间留给行动。
10. **标签勿漂移**：本章已定义的编号/职衔/规则名（类型码 vs 个体号、职位 vs 人名等）禁止混指；新含义须用新标签或当场改口并留下物证。
11. **共体状态勿静默切换**：若已确立「多人共用一具身体 / 脑内声 / 抢控」，禁止无过程地写成两具身体并排行动；分体、借壳、外化须写清触发、代价与当场可观察后果。
12. **计数口径勿混用**：身体数、名册位序、号牌数、在押人数等须各自命名；禁止用同一套数字在不同口径间偷换（如「点名到第 N」与「排位第 M」混为一谈）。
13. **无意义对白乒乓**：禁止 A 抛半截话 → B「什么/担什么/什么意思」→ A 再解释给读者听。第二句若只为给第一句搭台阶，删掉第二句，让第一句一次说完，或改成动作打断。

## 1. 去 AI 味（写时即守）

### 禁止（词句与节奏）

- **喊情绪**：禁止「感到/意识到/心中涌起/无比愤怒」；用动作、神态、生理、物件、停顿演。
- **翻译腔 / 作文拐杖**：禁止「令人难以置信」「如此美丽」「与此同时」「不仅如此」「值得一提」「不难看出」「由此可见」。
- **同义反复与极端词**：一个意思说两遍；「非常/极其/无比」删到只靠画面给程度。
- **端着的对话**：禁止人人出口成章、句句金句对诗；允许打断、吞字、说偏（服从人设）。
- **语域乱跳 / 无用修辞**：朴实文别硬塞典故；比喻不帮局面或爽感就删。
- **弱化副词堆砌**：微微/淡淡/缓缓/轻轻 不要密铺。
- **假人味**：禁止故意错字、乱加 emoji/烂梗、伪造「亲历细节」装真人（qu-ai-wei / Humanizer 共识）。

### 对话怎么写（硬要求）

- **一句一意图**：每句对白须推动拒绝/索取/威胁/试探/躲责中的一种；禁止只为「显得像对话」而多蹦一句。
- **禁解释台阶**：勿写「我要担。」「担什么？」——改成「你在这儿嚷，回头板子算我的。」或李馥直接插牌、退半步，不靠对方追问。
- **信息给够就停**：小吏不会把「一天挡三十个、挡错挨三十棍」讲成小作文；最多半句，其余用动作（插牌、抠漆、退进门框）。
- **可不通顺，不可无功能**：吞字、打断、答非所问可以；无来由的反问接力不行。
- **身份口吻**：门吏白话短句；禁戏剧腔半截悬念（「我要担」这种舞台台词）。

### 要求

- 句长有起伏；禁止整段同长、上下段对仗工整。
- 简体网文标点：对话用弯双引号“”；省略号用……；正文不用【】，不用「」『』作主引号。
- 去味 = 改外壳与节奏，**不得**为顺口补写新事实、新因果、新经历。

## 3. 网文推进与吸引力（番茄/起点底线）

### 3.0 冲突密度与情绪优先（防无意义剧情 · 推演硬闸）

规划梗概/细纲与写正文时，**冲突密度**与**读者情绪调动**同为最高优先级，高于「把过程写全」「把细节写真」。

- **先问情绪，再留场面**：每一段落笔前自问——这段把读者情绪往哪一格推（憋/怒/冷/狠/期待/忌）？推不动 = **无意义剧情**，删或并刀，禁止用说明书式过程填字数。
- **触发细节优先于过程细账**：只留能直接砸情绪的触发物（关门、棍尖、一口锅、一句「不合格」、刀出一寸）；考题原文、排队寒暄、陈设观光、同构事件的重复展开一律砍。
- **同构事件必须压缩**：同一叙事功能的重复节拍（连续求见被拒、连续过门考等）禁止各开细章「写详细」——细节一细，冲突就被稀释；蒙太奇/快切并刀，把篇幅留给情绪转向与下一冲突升级。
- **被辱/憋屈可给读者，不给主角嚼**：若需积压情绪，靠关门频率与反差堆给读者；禁止用羞辱特写、反复卡壳、长独白把冲突写成心理说明书。
- **详略服从加压**：过程说明永远让位给冲突升级；详写额度留给兑现、反转、代价与新压力，不留给过渡与展览。

### 3.1 章推进底线

- **短、快、狠**：对话与动作推进；少空叙述。
- **章内必有变化**：至少推进目标 / 信息 / 关系 / 风险之一；禁止复述细纲无场面。
- **当场兑现一拍**：赢一回合要有可摸结果（存证、立约、签字、丢脸），禁止「今天不定」连砍三刀还不落地。
- **章末只留一个钩**：未完成动作 / 未揭信息 / 下一拍压力；禁止总结讲课或双句升华。
- **章末钩勿复读上章**：禁止把上一章已经甩出、尚未兑现的同一句承诺原样再当章末钩（「去××」「找××」连甩两章）；须换成新压力、新物证或承诺的即时后果。
- **前钩须交账**：上一章末的未完成动作、即时威胁或关键物证，本章前半必须兑现、受阻或明确延后；禁止无解释搁置后另起新险。
- **峰值后勿泄压**：章内最高险/最高信息差之后，禁止立刻接一段无关议价、闲聊或复盘把张力摁回去；要么立刻入下一拍动作，要么章断。
- **峰值后勿叠钩 / 一章一主峰**：高潮拍之后禁止再连抛 2+ 个新悬念；也禁止再开一场具备独立目标、阻力与反转的完整第二主冲突；峰后只收结果、落代价或甩一个新压力。
- **状态突变须有桥**：身体归属、同行人数、地点、拘押/自由等关键条件变化时，须给出可观察触发、时间锚或代价；禁止场景一切换就默认变化已发生。
- **章首补因果拍**：若开章时人物已从自由变被押、共身变分身、获准变受罚等，开篇须尽快交代「谁触发、如何发生、付了什么代价」（可倒叙短拍，不可整段删除）。
- **谜团不得只增不解**：同一主线谜团连续两章只加不解时，第三章前必须结算至少一项旧疑问或排除一种解释；禁止以更多专名替代答案。
- **配角勿降成提词器**：有戏份的搭档/女主等须有可感知立场或代价（一句短反应、一次失手、一处身体代价即可）；禁止整章只当旁白问答机。
- **性别与称谓跟档案**：大纲/设定已定性别与称谓，叙述代词不得无故改口。
- **修仙/金手指线勿断**：若卷主题含气感/外挂，权谋章也要留一条可摸物件或未解式，别整章只开会。
- **限知**：只写观察者当下能感知的。
- **时间线自洽**：同卷各章「军训第几天 / 是否已结束」不得互相打架；「第 N 次」须有时间跨度或循环物证支撑。
- **线索要物证**：关键跳转（地名、凶手、组织）须有当场可摸痕迹或对白锚，禁止纯脑补飞跃。
- **记忆不能单独完成地点跳转**：角色「我记得去××」最多作动机；实际抵达须另有票据、路牌、印章、同伴带路等可复核锚，并在下场可被核对。

## 4. 自检（交付正文时）

在 `selfReview` / `finalSelfReview` 用一两句写清：

- 已清零的硬闸编号（如「0.2/0.11/0.12/0.13」与 §3.0 冲突密度/情绪优先、§3 前钩交账/一章一主峰/状态桥/谜团债）；
- 已核逻辑链（含共体状态、计数口径、性别称谓、章首因果）；
- 本章兑现的变化 + 上章钩如何交账 + 章末唯一钩是什么 + 该钩与上章末是否不同；
- 一句点明：删掉了哪些无意义过程与对白乒乓、保留了哪几个触发细节砸情绪。

禁止空话「已注意文笔」。
