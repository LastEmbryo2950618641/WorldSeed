## 0. 交付硬闸（写完先自查，不过则改后再交）

正文 `chapterDraftProposal(s)` 交付前，下列任一命中必须删改，禁止「写完再润色」 internally 跳过：

1. **复盘已演场面**：禁止「你刚才说了三句话 / 一句问一句摆条文 / 他明白了这意味着」式作者复盘。
2. **不是A而是B / 是A不是B**（叙述层）：解释腔对比一律改成动作或一句结论；台词里偶发可留。
3. **否定排比**：禁止「没有…没有…」「不是…也不是…只是…」连发。
4. **音量反差模板**：禁止「声音不大，却…」。
5. **代写心理怕什么**：禁止「他不是不敢，他是怕…」；用捏纸、停顿、抢话演。
6. **双收束升华**：章末禁止对仗双「他知道… / 也知道…」；只留一个动作或一条具体信息。
7. **破折号癖**：叙述层少用 ——；能用句逗就别用。
8. **空话升华**：禁止命运齿轮、空气凝固、时间静止、未来可期、意义深远。

## 1. 去 AI 味（写时即守）

### 禁止（词句与节奏）

- **喊情绪**：禁止「感到/意识到/心中涌起/无比愤怒」；用动作、神态、生理、物件、停顿演。
- **翻译腔 / 作文拐杖**：禁止「令人难以置信」「如此美丽」「与此同时」「不仅如此」「值得一提」「不难看出」「由此可见」。
- **同义反复与极端词**：一个意思说两遍；「非常/极其/无比」删到只靠画面给程度。
- **端着的对话**：禁止人人出口成章、句句金句对诗；允许打断、吞字、说偏（服从人设）。
- **语域乱跳 / 无用修辞**：朴实文别硬塞典故；比喻不帮局面或爽感就删。
- **弱化副词堆砌**：微微/淡淡/缓缓/轻轻 不要密铺。
- **假人味**：禁止故意错字、乱加 emoji/烂梗、伪造「亲历细节」装真人（qu-ai-wei / Humanizer 共识）。

### 要求

- 句长有起伏；禁止整段同长、上下段对仗工整。
- 简体网文标点：对话用弯双引号“”；省略号用……；正文不用【】，不用「」『』作主引号。
- 去味 = 改外壳与节奏，**不得**为顺口补写新事实、新因果、新经历。

## 2. 逻辑与连贯（落笔前核对，写入 selfReview）

1. **行为动机** 2. **因果铺垫** 3. **资源守恒** 4. **身份与知情**  
5. **伤势与状态** 6. **战力与规则** 7. **情绪与关系** 8. **时间线与空间**

冲突先改稿或补交代。图证据与已发布正文冲突时，以图与正文为准，不得靠遗忘圆场。

## 3. 网文推进与吸引力（番茄/起点底线）

- **短、快、狠**：对话与动作推进；少空叙述。
- **章内必有变化**：至少推进目标 / 信息 / 关系 / 风险之一；禁止复述细纲无场面。
- **当场兑现一拍**：赢一回合要有可摸结果（存证、立约、签字、丢脸），禁止「今天不定」连砍三刀还不落地。
- **章末只留一个钩**：未完成动作 / 未揭信息 / 下一拍压力；禁止总结讲课或双句升华。
- **修仙/金手指线勿断**：若卷主题含气感/外挂，权谋章也要留一条可摸物件或未解式，别整章只开会。
- **限知**：只写观察者当下能感知的。
- **时间线自洽**：同卷各章「军训第几天 / 是否已结束」不得互相打架。

## 4. 自检（交付正文时）

在 `selfReview` / `finalSelfReview` 用一两句写清：

- 已清零的硬闸编号（如「0.1/0.2/0.6」）；
- 已核逻辑链（无冲突或如何补）；
- 本章兑现的变化 + 章末唯一钩是什么。

禁止空话「已注意文笔」。
