# 默认描写规则

> 职责：切镜、密度、铺开顺序。不管用语和题材腔。

## 优先级

切镜 / 锁景 ＞ 密度（铺开或收束）＞ 铺开顺序。顺序只在密度=铺开、且当前距离够宽时生效。

## 切镜策略

无额外约束时，由当前场景自行选择持镜、切人和远近。换地点先定场再推进。可操作切口：动作完成、话轮交接、观察者转身、换地。转场用声、光、气味或同一物件衔接，不要写摄影术语。

## 密度策略

首次看见某人/某地允许一次铺开；再出场只写相对上次的变化。对峙、认人、近身升密；赶路、交代、纯对白降密。群像每人一个辨识点。

## 铺开配方（仅密度=铺开时）

先整体后局部。人物默认上→下；衣着默认外→内；空间默认远→近。同一段不跳轴。近景只写最后一槽。

## 禁止

禁止把「镜头推进 / 切到 / 特写」写进正文。禁止为写完清单而拉远。不改世界事实与人物未知信息。
