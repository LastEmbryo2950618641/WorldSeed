# 远近调度

> 职责：切镜、密度、铺开顺序。不管用语和题材腔。

## 优先级

切镜 / 锁景 ＞ 密度（铺开或收束）＞ 铺开顺序。顺序只在密度=铺开、且当前距离够宽时生效。

## 切镜策略

换地点、开战、入城、行军时先定场（空间、人数、天气、动线），再阶梯落到可跟随的人或物。未换地不要无故拉回大远景。同一段不要远→近→远来回拉，除非战乱或眩晕。

## 密度策略

定场段降密；落到人之后按默认密度。不要在远景里给每个人写全身。

## 铺开配方（仅密度=铺开时）

空间：远（轮廓/队列）→ 中（谁和谁）→ 近（手/眼/物件）。人物仍先整体后局部。

## 禁止

禁止整段悬浮俯拍后不落地。看不清的远处就写看不清。
