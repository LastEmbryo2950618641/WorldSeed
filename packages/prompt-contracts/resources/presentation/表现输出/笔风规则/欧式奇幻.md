# 欧式奇幻

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

剑与魔法的西式奇幻书面语。纹章、领主、教会、契约、血脉是世界零件，要写进场面。

## 合格描写单位（填充描写配方的槽位）

纹章或披风轮廓 → 武器与护甲材质 → 圣徽或契约印记 → 眼睛。

## 句式

比轻小说更稳，比史诗更短。专名用译名习惯（骑士、咏唱、魔导），少日式技能栏。

## 可多用 / 禁用

可多用：领主、教会、契约、魔导、骑士团。禁用：修仙、公会任务弹出、吐槽口癖。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

远近调度的定场用城堡、森林、城墙轮廓，不用仙山洞府。
