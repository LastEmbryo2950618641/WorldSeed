# 都市异能

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

当代都市底，能力当秘密或事故来写，不当游戏技能。

## 合格描写单位（填充描写配方的槽位）

普通人的外表 → 能力留下的痕迹（焦痕、耳鸣、监控死角）→ 想隐瞒的动作。

## 句式

能力发动写感觉和后果，不写技能面板。

## 可多用 / 禁用

可多用：觉醒、污染、组织、善后。禁用：经验值、冷却完毕、宗门。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

对峙升密写痕迹和距离，不写升级。
