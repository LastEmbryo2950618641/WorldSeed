# 轻小说

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

当代口语叙事，轻、快、可吐槽。像给读者讲，不像史书。

## 合格描写单位（填充描写配方的槽位）

一个萌点、反差点或口癖嵌进动作。禁止说明书和外貌课。

## 句式

短句为主。内心吐槽用短破折或单独短段，不要大段括号演讲。

## 可多用 / 禁用

可多用：日常口语、角色口癖。禁用：之乎者也、功法歌诀、欧化从句堆叠。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

近景只留那一个辨识点；不要把头到脚走完。
