# 军事战争

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

条令、呼号、弹药、方位。残酷可以写，不美化，不游戏化。

## 合格描写单位（填充描写配方的槽位）

军衔与装具 → 枪声方向 → 泥、血、无线电里的一声。

## 句式

短促。时间用几点几分或距离。少抒情。

## 可多用 / 禁用

可多用：呼号、阵地、补给、交火。禁用：技能、经验、热血BGM旁白。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

远近调度用战场轮廓；近景跟准星和手走。
