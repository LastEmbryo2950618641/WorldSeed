# 悬疑恐怖

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

信息短缺。只写能被看见、听见、闻见的异常，不解释超自然原理。

## 合格描写单位（填充描写配方的槽位）

错位的日常物件 → 声音来源不明 → 身体反应（冷、停、想回头）→ 一处不该在这里的细节。

## 句式

短。留白。少形容词。禁止作者宣布「很恐怖」。

## 可多用 / 禁用

可多用：具体物件名、脚步、门缝。禁用：鬼气森森、只见、血盆大口套话、全面解说。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

限知主观优先。升密写生理，不写怪物设定集。
