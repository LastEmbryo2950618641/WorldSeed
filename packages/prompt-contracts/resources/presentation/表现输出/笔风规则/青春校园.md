# 青春校园

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

学期、教室、社团的轻口语。可以羞、可以呛，不要油腻旁白。

## 合格描写单位（填充描写配方的槽位）

校服或书包的一个磨损点 → 座位距离 → 没说出口的半句。

## 句式

对话量大可以，叙述别替角色宣布心动定义。

## 可多用 / 禁用

可多用：学期、社团、测验。禁用：后宫点名、身体扫描、职场黑话。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

近景跟课桌和余光走。禁止从头到脚。
