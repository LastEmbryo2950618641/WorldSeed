# 史诗奇幻

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

高位叙事，写文明与战争的分量。句子可以更长，但仍要落地到可看的旗帜、城门、尸体。

## 合格描写单位（填充描写配方的槽位）

军势或地貌 → 族裔/王国标志 → 一件传说器物 → 一个凡人细节（以免悬浮）。

## 句式

叙述可庄，对话按阶层分开。禁止每句排比。

## 可多用 / 禁用

可多用：王庭、盟约、古语、天命、废都。禁用：吐槽、升级提示、现代口语旁白。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

远景定场合法；落到人时必须给一个凡人尺度的细节。
