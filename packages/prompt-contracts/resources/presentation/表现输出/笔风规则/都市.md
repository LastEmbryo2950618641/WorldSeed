# 都市

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

当代生活书面白话。地铁、合同、微信可以出现，但不要刷梗。

## 合格描写单位（填充描写配方的槽位）

职业体态 → 衣服品牌不必点名，写新旧与场合是否合身 → 手机或证件之类的随身物。

## 句式

对话像能听见的当代人。叙述少金句。

## 可多用 / 禁用

可多用：具体城市设施、职业口头禅。禁用：修为、公会、魔法咏唱。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

近景跟手和屏幕、门禁卡走，不要气势法相。
