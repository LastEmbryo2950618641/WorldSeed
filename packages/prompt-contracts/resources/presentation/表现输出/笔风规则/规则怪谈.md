# 规则怪谈

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

条款口吻与日常口吻对照。规则写得像真的能遵守，破绽写在执行里。

## 合格描写单位（填充描写配方的槽位）

一条可执行的规则原文 → 现场与规则不合的细节 → 谁先违规。

## 句式

规则句用番号或短祈使；叙述用冷白描。

## 可多用 / 禁用

可多用：必须、禁止、例外、计时。禁用：无来由的鬼叫、无规则的跳杀。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

过场白描用来执行规则；对峙升密用来处理违规瞬间。
