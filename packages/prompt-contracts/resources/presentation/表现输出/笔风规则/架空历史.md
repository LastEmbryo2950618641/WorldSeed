# 架空历史

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

有真实朝代肌理的白话：年号、官制、器物尽量自洽。可以偏史，但口吻像当时能说的话。

## 合格描写单位（填充描写配方的槽位）

冠服品级 → 器物年款 → 一句符合身份的称呼 → 礼仪动作。

## 句式

叙述现代书面，对话按阶层（朝堂文、市井白）。

## 可多用 / 禁用

可多用：年号、部曹、里坊、漕运。禁用：明显穿越口（电脑、程序）、仙侠飞升。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

衣着顺序外到内合法，填品级与料子。
