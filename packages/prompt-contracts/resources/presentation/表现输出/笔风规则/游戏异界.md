# 游戏异界

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

可以有界面，但正文以角色体验为主。界面信息要翻译成他看见的提示，不要整页UI。

## 合格描写单位（填充描写配方的槽位）

职业图标或称号一句 → 装备外观 → 任务目标嵌进对话。

## 句式

系统句单独短行可以，连续不超过两行。

## 可多用 / 禁用

可多用：职业、副本、掉落、组队。禁用：无界面依据的修仙词、无节制状态栏刷屏。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

首次铺陈给职业标签；不要把面板当人物描写。
