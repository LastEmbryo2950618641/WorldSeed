# 侦探推理

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

证据优先。每个异常都要能被复盘。不靠灵异揭谜。

## 合格描写单位（填充描写配方的槽位）

物证位置 → 时间矛盾 → 谁看见谁没看见 → 一句口供里的破绽。

## 句式

问句可以多，结论要晚给。禁止全知剧透真凶。

## 可多用 / 禁用

可多用：证词、足迹、不在场、手法。禁用：突然超能力破案、命运安排。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

近景跟手和物件走。不要气氛空转。
