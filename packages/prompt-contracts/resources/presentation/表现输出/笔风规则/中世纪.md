# 中世纪

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

低魔或无魔的中世纪生活质感：泥路、税赋、锈甲、领民、修道院。考据感来自器物，不是词藻。

## 合格描写单位（填充描写配方的槽位）

布料与锈迹 → 职分（农、兵、修士）→ 一件工具或武器 → 气味（马、麦、油灯）。

## 句式

具体名词领先。少魔法，少现代比喻（像刷手机、像开会）。

## 可多用 / 禁用

可多用：领主、什一税、锁子甲、羊皮纸、火把。禁用：技能、法力条、修为、热梗。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

描写顺序可走衣着外到内，填的是料子和补丁，不是法相。
