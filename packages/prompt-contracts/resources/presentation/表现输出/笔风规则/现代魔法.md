# 现代魔法

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

当代城市里的法术当违章作业：仪式、代价、掩盖。不像中世纪吟游。

## 合格描写单位（填充描写配方的槽位）

日常物件被征用为法器 → 代价的生理痕迹 → 监控或邻居。

## 句式

口语叙述 + 偶尔的术词。术词不要拉丁文墙。

## 可多用 / 禁用

可多用：结界、代价、清场、匿名。禁用：公会任务板、修仙洞府、骑士。

## 与描写规则的接口
