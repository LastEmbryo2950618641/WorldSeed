# 科幻星际

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

技术名词要可执行：船、轨道、生命维持、延迟。奇观也要落到仪表和呼吸。

## 合格描写单位（填充描写配方的槽位）

舷窗或船体曲线 → 界面读数一句 → 舱内气味/失重感。

## 句式

可以用术语，但每段最多一次解释。禁止说明书连载。

## 可多用 / 禁用

可多用：轨道、跃迁、协议、舱压。禁用：灵气、魔法、无依据的穿越口头禅。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

定场用尺度（行星、舰队）；近景必须给舱内人体尺度。
