# 日式异界

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

转生/穿越到剑与魔法世界的日式奇幻口吻。公会、迷宫、讨伐是生活用语，不是外挂广告。

## 合格描写单位（填充描写配方的槽位）

种族或职业轮廓 → 武器类型 → 一件护身符或公会徽章 → 表情。状态栏最多一句，禁止整屏技能表。

## 句式

轻小说短句 + 必要专有名词。专名可用（哥布林、史莱姆、冒险者），不要中英混杂说明书。

## 可多用 / 禁用

可多用：迷宫、公会、讨伐、魔法咏唱、转生。禁用：宗门飞升、修为瓶颈、现代网络热梗墙。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

首次铺陈给种族/职业标签即可，不要西洋纹章大课。
