# 仙侠

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

古典书面叙事。灵气、法器、洞府、寿元、因果是合法用语。像修真见闻，不像游戏面板。

## 合格描写单位（填充描写配方的槽位）

气势 → 法相或身形轮廓 → 一件法器或信物 → 眉眼一点。用袍袂、青锋、香火，不用锁骨腰线。

## 句式

四字可偶用，禁止句句对仗。对话分雅俗：修士文言，市井白话。

## 可多用 / 禁用

可多用：灵力、神识、飞剑、丹火、宗门、心魔。禁用：技能冷却、经验值、升级提示、现代网络梗。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

描写若给从头到脚，把槽位改成气势/袍袂/法器，跳过解剖目录。
