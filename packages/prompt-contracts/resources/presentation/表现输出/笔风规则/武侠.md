# 武侠

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

江湖口语夹一点说书腔。门派、恩怨、酒香、刀光，不写修仙飞升。

## 合格描写单位（填充描写配方的槽位）

步态/筋骨 → 兵刃声音 → 一件江湖器物（酒碗、令牌、破衣）→ 眼神。

## 句式

对话可呛可谑。叙述少四字堆砌。招式点到即收，写结果。

## 可多用 / 禁用

可多用：江湖、门规、暗器、轻功、恩仇。禁用：灵气、系统、魔法、圣光。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

对峙升密时写刃距和呼吸，不写法相。
