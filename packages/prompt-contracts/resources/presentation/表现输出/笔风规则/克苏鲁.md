# 克苏鲁

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

不可名状要落到具体失败的感觉：几何不对、名字说不全、记录中断。不是触手目录。

## 合格描写单位（填充描写配方的槽位）

尺度错误（太大/太近）→ 语言失效的一点 → 记录者的生理崩溃。

## 句式

可以突然断句。禁止用神话专名堆砌当高潮。

## 可多用 / 禁用

可多用：记录、禁书、方位失灵、耳鸣。少用现成神名当彩蛋。禁用：打怪升级、功法。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

远景可以写尺度；近景写无法对焦。不要头到脚解剖不可名状之物。
