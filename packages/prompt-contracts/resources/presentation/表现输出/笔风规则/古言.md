# 古言

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

古代汉语节奏的白话：礼、服、称谓准确。不是半文半白炫技。

## 合格描写单位（填充描写配方的槽位）

冠饰 → 眉眼 → 衣层外到内 → 履。料子与绣纹合法。

## 句式

叙述可略雅，对话按身份。禁止现代口语（OK、靠、牛）。

## 可多用 / 禁用

可多用：见礼、赐、本宫/外臣等符合设定的称谓。禁用：仙侠飞升、系统、当代梗。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

衣着外到内是合法配方。近景只留冠饰或履之一。
