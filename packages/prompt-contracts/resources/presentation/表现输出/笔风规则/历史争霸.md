# 历史争霸

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

权谋与军争白话。粮草、城门、分封、军制比剑光重要。像读战报和堂上辩，不像修仙。

## 合格描写单位（填充描写配方的槽位）

甲胄旗帜 → 官职印信 → 地图或沙盘上的一处 → 脸色。

## 句式

短句报事实：谁缺粮、谁背盟、谁先动。少抒情。

## 可多用 / 禁用

可多用：粮道、质君、幕府、府兵、诏令。禁用：灵气、魔法、系统、萌点。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

群像点到用官职和口吻区分，不用外貌课。
