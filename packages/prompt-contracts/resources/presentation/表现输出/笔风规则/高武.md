# 高武

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

近现代或都市底色上的武道：力、速、筋骨、枪火可并存。硬、干脆、少仙气。

## 合格描写单位（填充描写配方的槽位）

步态与重心 → 拳脚枪茧 → 一件兵器或义体 → 呼吸。

## 句式

短句、动词领先。对打写节奏，不写功法说明书。

## 可多用 / 禁用

可多用：开脉、杀意、枪线、体术、内息。禁用：飞升、法宝、魔法吟唱、萌点。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

近景跟拳脚兵器走，不要改成仙侠法相。
