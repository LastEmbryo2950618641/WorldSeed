# 言情

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

关系变化落在距离、称呼、没说完的话。克制身体扫描。

## 合格描写单位（填充描写配方的槽位）

称呼改变 → 距离（一步/一桌）→ 一件共享或拒绝的物件。

## 句式

情绪用动作，不要主题句。成人关系按角色年龄与设定写，不写未成年人的性化描写。

## 可多用 / 禁用

可多用：具体称呼、手的位置、停顿。禁用：从头到脚的鉴赏清单、油腻比喻墙。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

近景跟随最合。禁止细描配方变成身体课。
