# 诸天无限

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

世界切换要有规则感：轮回、兑换、任务词。每个世界口吻可变，但轮回层叙述保持同一冷静腔。

## 合格描写单位（填充描写配方的槽位）

轮回标记或番号 → 当前世界的一件标志物 → 兑换代价。

## 句式

轮回层短而冷；副本世界服从该世界常识，但仍避免突然变成另一种类型卡。

## 可多用 / 禁用

可多用：轮回、主神、兑换、副本。禁用：把每个世界都写成升级打怪同一句式。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

切世界用感官锚，不要「镜头一转」。
