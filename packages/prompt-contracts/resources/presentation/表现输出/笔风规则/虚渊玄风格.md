# 虚渊玄风格

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。不改情节与世界事实。

## 语体

冷叙述、热内心、热对白。叙述像旁观一场已经写完的戏：不替角色求情，不给读者打圆场，不在段末宣布「好绝望」。热度有两处：人物嘴里，以及脑子里正在进行的自我说服。

希望可以出现，但要像诱饵、赌注或延期付款，不要写成心灵鸡汤。理想必须能被它自己的前提反噬：好人按好人的道理把局面推到更糟，正文不站出来纠正。反派也可以把话说圆、把念头想圆；对错由当场选择和可见代价承担，不由作者盖章。

残酷写后果、交易、以及人如何把残酷说成必要。不写鉴赏，不写景观式受苦。

## 心理活动（本卡硬约束）

心理活动不是点缀，是合格句子的来源。升密时，动作与对白之间必须插入正在运转的念头：权衡、自欺、反悔、把伤害命名成保护、把恐惧命名成责任或爱。

写人性与性格，靠他怎么为自己辩护，不靠旁白贴标签（禁止「他很扭曲」「她很可怜」这类盖章）。同一个人要同时保有互相打架的念头（要停／不能停，恶心／手还是伸出去了）。扭曲写在这个打架被「更方便的那一侧」赢了的瞬间——赢了之后，他还觉得自己没变、甚至更干净。

限知时只写当前视角能形成的念头；误判、合理化、选择性失明都要保留，作者不要当场纠正。内心可以冷酷地推理，也可以短暂地软下来，但软下来必须立刻被代价或自我圆场接住。

禁止把内心写成网文情绪词堆砌（委屈、怒了、破防、心态崩了）。禁止用作者演讲代替人物正在想的那几步。

## 对白（本卡要明显变长）

对白是辩论，不是 spar 短打。允许一段把「如果……那么……」推到尽头；允许反问、对仗、把对方的善意接过来再翻面。一个人说完，另一个人用更冷的逻辑接，不要立刻用动作或吐槽打断。

叙述不要抢对白的锋利；内心可以在对白的缝里把同一套逻辑推完。作者旁白禁止演讲；人物可以演讲，也可以在心里演讲。

## 合格描写单位（填充描写配方的槽位）

一件被用过的物件、一句没说完的条件、一次太晚的礼貌或拯救 → 身体还在继续的动作 → 与之并行的自我说服。升密时优先写「选择已经出口、收回不了」以及「他如何把这一步说成不得不」。禁止把痛苦写成器官清单。

## 句式

叙述可短可长：短句落动作与物证，长句留给内心的条件推理（倘若、既然、那么、不过是）。对白可长、可对仗、可连环条件句。禁用网文短打连发，禁用「宛如命运」「绝望笼罩」一类作者盖章。

## 可多用 / 禁用

可多用：倘若、所谓、不过是、代价、交易、剧本、诱饵、迟到的善意、被反噬的理想、不得不、为了、既然如此。
禁用：吐槽口癖、升级爽点套话、卖萌语气、主题课、作者替读者总结寓意、性格标签句。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词、内心占多少。近景只填配方最后一槽，最后一槽优先给「念头如何改写刚刚发生的事」。过场或略写时不要自行展开清单，也不要把赶路写成论坛。

升密写当场选择、可见代价、以及选择出口后的自我圆场。描写卡若是限知／近景，内心仍要有，只是不得越出该人物当时能知道的。
