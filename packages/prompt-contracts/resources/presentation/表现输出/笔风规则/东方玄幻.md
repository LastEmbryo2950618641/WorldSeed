# 东方玄幻

> 职责：语体、用词、合格描写单位。不管何时切镜、铺多少。

## 语体

东方异世的宏大白话：王朝、血脉、功法、妖族可以直说，但要嵌进场面，不单独开设定课。

## 合格描写单位（填充描写配方的槽位）

气机或压迫感 → 服饰纹样/族徽 → 兵器或命宝 → 一处眼睛或伤疤。

## 句式

短句推进冲突，长句只给一次压场。少用轻小说括号吐槽。

## 可多用 / 禁用

可多用：血脉、灵体、皇朝、妖丹、战场杀意。禁用：公会任务板、哥布林、圣骑士、系统叮。

## 与描写规则的接口

描写规则决定何时切镜、写多细、按什么顺序扫；本文件只改槽位里填什么、用哪些词。近景只填配方最后一槽；过场或略写时不要自行展开清单。

争霸场面用器物和军势填槽，不要写成西式纹章课。
